# Fixtures

Next.js App Router, TypeScript e Tailwind CSS. Dependências gerenciadas com Bun.

## Desenvolvimento

```sh
bun install
bun dev
```

Abra http://localhost:3000.

## Validação

```sh
bun run lint
bun run typecheck
bun run build
```

Base inicial com página de apresentação. Integração com API de futebol, filtros e exportação .ics ainda não implementados.
